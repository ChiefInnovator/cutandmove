# App icon

The production icon fills its square canvas, without a baked-in gray surround, inset tile, outside border, or drop shadow. macOS may apply its own icon presentation.

All seven asset sizes (16 through 1024 pixels) are derived from the same replacement artwork. The website uses the same asset catalog artwork.

Created using the built-in image generation tool with the original icon as the edit target. Prompt:

> Edit this app icon for Cut & Move. Preserve its recognizable black scissors, smiling Finder-like white face, blue upper-right folded corner. Deliver a production 1024x1024 square full-bleed app icon: enlarge the white icon face to fill the ENTIRE square canvas edge to edge, with no gray outer background, no inset rounded-square tile, no outer border, no padding, no drop shadow, no rounded outside corners. White face background extends to all four edges; blue folded corner extends to top and right edges. Keep the entire scissors and smile visible and centered with balanced proportions. Crisp smooth edges. No text. Output only the flat square icon artwork.
