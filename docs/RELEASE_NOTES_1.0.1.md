# Cut & Move 1.0.1

- Direct macOS distribution using MacEdgeLight's release workflow; no Mac App Store submission.
- MILL5 Developer ID signed and Apple-notarized app, supplied as a signed DMG and ZIP.
- SHA-256 checksums included for downloaded packages.
- PolyForm Strict 1.0.0 license.

Requires macOS 26.1 or later. Download access requires membership in the private GitHub repository. Open the DMG, drag CutAndMove into Applications, and grant Accessibility access when prompted.
