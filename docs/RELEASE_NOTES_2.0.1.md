# Cut & Move v2.0.1

Version 2.0.1 (build 6). Requires an Apple silicon Mac (M1 or later) running macOS 26.1 or later.

- Apple-silicon-only app and Finder Sync extension. Intel binaries are no longer included.
- Release verification rejects packages containing any architecture other than arm64.
- Updated website, README, and machine-readable product facts with the hardware requirements and full version number.
- Includes the Finder integration from v2.0.0: right-click Cut, Move Here, and Cancel Cut; toolbar actions; pending-cut badges; and shared keyboard/context-menu cut state across local folders and mounted drives.

Distributed directly through GitHub as a MILL5 Developer ID signed, Apple-notarized app in a signed DMG or ZIP. No Mac App Store version. The existing v2.0.0 release is unchanged.
