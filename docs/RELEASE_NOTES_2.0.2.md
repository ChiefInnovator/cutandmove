# Cut & Move v2.0.2

Version 2.0.2 (build 7). Requires an Apple silicon Mac (M1 or later) running macOS 26.1 or later.

- Clearer keyboard setup: distinguish missing Accessibility access, unavailable monitoring, and ready-to-use shortcuts.
- Retry Monitoring and a persistent Done action replace the automatically dismissed success screen; permission diagnostics can grow with their content.
- The menu's Keyboard Shortcut Settings action matches its purpose, and About's Website action opens the Cut & Move homepage.
- Finder Move and Cancel Cut labels use the correct singular or plural item count.
- Download pages show complete hardware requirements beside the buttons, improve text/button contrast, and clarify published versus development-preview help.
- Shared Finder keyboard/menu cut state, collision checks, cancellation, and partial-failure handling remain unchanged.
- Release packaging now requires a notarization ticket and Gatekeeper acceptance for the signed outer DMG as well as the app.

Distributed directly through GitHub as a MILL5 Developer ID signed, Apple-notarized app in a signed DMG or ZIP. No Mac App Store version.
